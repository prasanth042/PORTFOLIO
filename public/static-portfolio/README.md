# Prasanth C — Portfolio (HTML / CSS / JavaScript)

A modern, responsive personal portfolio built with plain **HTML5**, **CSS3**, and **vanilla JavaScript** — no frameworks, no build step.

## 📂 Files
```
index.html      — markup
styles.css      — design system (Midnight Indigo theme, glassmorphism)
script.js       — mobile nav, scroll reveal, contact form, active link
assets/         — portrait + project images
```

## 🚀 Run locally (VS Code)
1. Download / clone this folder.
2. Open in **VS Code**.
3. Install the **Live Server** extension → right-click `index.html` → **Open with Live Server**.

Or just double-click `index.html` to open in your browser.

## ☁️ Publish on GitHub
1. Create a new GitHub repo, e.g. `prasanth-portfolio`.
2. Upload these files (drag-drop on github.com or `git push`).
3. Go to **Settings → Pages → Source: main / root → Save**.
4. Your live site: `https://<your-username>.github.io/prasanth-portfolio/`

## ✏️ Customize
- Resume link: edit the `Download Resume` `<a href="#">` in `index.html`.
- LinkedIn / GitHub: update social URLs in `index.html`.
- Colors: tweak the CSS variables at the top of `styles.css`.
